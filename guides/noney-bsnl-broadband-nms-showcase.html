Practical guide

Explore the Noney Broadband NMS showcase

Run the public static gateway and documentation locally without requiring the retired production server or any private customer and infrastructure data.

Related project: Noney BSNL Broadband NMS — complete case study

For: Portfolio reviewers who want to inspect the public gateway, screenshots, and documentation without the retired production backend.

Before you start

Prerequisites

  • A modern browser
  • Python 3 or another static HTTP server
  • The public showcase repository only; no private production credentials or customer data are required

Procedure

Step by step

  1. Clone the public repository, which contains the static gateway, documentation, screenshots, messages, and demonstration assets—not the private production backend.
  2. Review README.md and docs/projectdoc.md for project context, system modules, deployment diagrams, operational boundaries, and status.
  3. Start a static server and open http://localhost:8000 to inspect the gateway experience.
  4. Treat redirect-config.json as demonstration configuration. Replace its example endpoints only in a controlled deployment and never commit private infrastructure addresses.
  5. Use the screenshots and NetVision demonstration to review the operational interface without reconnecting the retired production environment.
  6. Preserve the documented privacy boundary: do not add customer information, credentials, topology, OLT configuration, or private server code to the public repository.

Command reference

git clone https://github.com/Guang84/Noney-BSNL-Broadband-NMS.git
cd Noney-BSNL-Broadband-NMS
python3 -m http.server 8000

Verify

Confirm the result

  • The public gateway, maintenance state, messages, and screenshots load locally
  • redirect-config.json contains demonstration-safe values only
  • Documentation consistently identifies the production server as retired

Troubleshooting

Common boundaries and failure checks

  • A missing production endpoint is expected: the operational backend is intentionally retired and not part of the public showcase.
  • Do not add private tunnel URLs, customer records, OLT credentials, or internal topology to make the demo appear live.
  • Use the static documentation and screenshots as the authoritative portfolio view.
