About / Guang

Technical work grounded in practical problems.

I’m a BCA graduate and technical builder with hands-on broadband/network operations experience. My work spans networking, Linux, system administration, cybersecurity, automation, software projects, AI and practical engineering.

What GLab is for

GLab connects projects to the reasoning behind them: architecture, implementation notes, setup guides, validation checklists, limitations and lessons learned. It is intentionally built as a lightweight static site that stays inspectable and easy to maintain.

Working principles

  • Prefer understandable tools over unnecessary complexity.
  • Keep security work inside explicit authorization boundaries.
  • Document operational context without exposing private data or infrastructure.
  • Use technology to improve practical work, not merely to add features.
